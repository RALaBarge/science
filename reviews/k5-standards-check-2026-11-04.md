# K-5 footer standards check, 2026-11-04

Scope: the 23 unit pages in `k-5/` (plus `unit-00`, which has no PE list, only an NGSS practices note). Each footer code and each line in the "Michigan Science Standards this unit earns" list was compared with the official performance-expectation (PE) text.

## Sources
- NGSS PE text: nextgenscience.org `dci-arrangement` pages for every code used (fetched via BrowserBox `fetch.get`, saved in the scratchpad `std\` folder).
- Michigan: the Michigan Science Standards (MDE, 2015) are the NGSS PEs adopted with the same codes in K-5 (K-PS2-1 ... 5-ESS3-1, K-2-ETS1-x, 3-5-ETS1-x). I could NOT fetch the MDE document itself (the michigan.gov science page URLs I tried returned 404), so "no K-5 code differences between Michigan and NGSS" is from knowledge, not confirmed against the MDE PDF.

## Result
- Every code exists, is in the right grade and strand, and its description is about the right PE. No wrong codes.
- One description error fixed: `2-LS2-1` said plants need sunlight "or" water; the PE says "and". Edited in `unit-2-b-plants-animals-and-habitats.html` (tutor-notes list).
- Judgment calls left alone: 3-5-ETS1-3 on the life-cycles unit (see table), and K-ESS2-2 wording on unit K-C.
- Footers (the `<footer>` line) only list codes; all footer codes match the tutor-notes lists on each page.
- Whether each lesson truly covers its PE (beyond the stated student evidence) was not audited lesson by lesson.
