# Accessibility, shared fixes: done and remaining

Date 2026-11-06. Source files only; `dist/` is regenerated by `node build.mjs`. Exit codes: build 0, `tests/links.test.js` 0, `tests/k5-activities.test.js` 0.

## Done

- **Skip link and landmark (build step).** `build.mjs` `a11y()` runs inside `wrap()` for every built page (61 lessons, extras, index, arcade, design log, six games). It adds `<a class="skip-link" href="#main">Skip to main content</a>` as the first thing in the body, gives `<main>` `id="main" tabindex="-1"` (falls back to the `<h1>` on a page with no `<main>`), and appends `shared/a11y.css` and `shared/a11y.js` last in the page. Lesson pages were not edited.
- **`<main>` and headings.** `index.html`, `arcade.html`, `design-log.html` and the six `games/*.html` now use `<main class="wrap" id="main">` instead of `<div class="wrap">`. The index "Science Arcade" card heading is an h2 (was h3 under the h1), which fixes the h1 to h3 jump. `shared/apply-retro.mjs` was updated to look for the new wrapper. 6th unit-14 (h2 to h4) is a lesson page and is left for the content pass.
- **Focus.** `shared/core.css` ring now covers links, selects, textareas, canvas and `[tabindex]` (3px). Arcade cards no longer set `outline:none` and show a 3px ring in the card colour. Lesson pages already had `:focus-visible`. Forced-colors uses `Highlight`.
- **Focus return and Tab trap (`shared/core.js`).** The quiz and facts dialogs remember the opener, return focus to it on close, and keep Tab inside the dialog. During a game demo the skip link is exempt from the "any key starts the game" handler; Enter on a link no longer fires a shot or advances a level in the games.
- **Reduced motion.** `a11y.css` and `core.css` turn off CSS animation, transitions and smooth scroll under `prefers-reduced-motion: reduce`, on the hub, the lesson map and all pages. The six games already read `Arcade.reduceMotion` for particles, camera easing and pulses (the scope survey missed that), so game logic is untouched.
- **Slider `aria-valuetext`.** `shared/a11y.js` builds it from the label's readout, for example "Base added: 12 mL (...)" gives "12 mL". It updates on input and on readout changes (MutationObserver). 160 of 169 sliders in the built pages are covered.
- **Classic contrast (light theme only; Retro and Classic dark are unchanged).**

- **Forced colors.** The Retro h1 gradient text uses `CanvasText` with no background in forced-colors mode (index and lessons, verified rendered).

## Checked (Playwright, 73 built pages, Retro and `?style=classic`)

No page errors. Skip link is the first Tab stop, visible when focused, and Enter moves focus to `#main` on every page. Reduced-motion emulation leaves no infinite running animation. Computed Classic light tokens match the table; Classic dark and Retro keep their values. Arcade card ring, quiz/facts focus in and back out verified.
